8. MODIFICAR EL CUPO DE UNA ACTIVIDAD

Instrucciones ejecutadas:

```
futbol.cupo = 25
futbol.save()

ActividadDeportiva.objects.filter(
    id=futbol.id
).values("nombre", "cupo").get()
```

Resultado:

```
{'nombre': 'Fútbol', 'cupo': 25}
```
El cupo de Fútbol se modificó de 20 a 25 y el cambio quedó guardado en la base de datos.
